# IT Support Portfolio

Hi, I'm Denns Lawrence Lagang, a BSIT student building hands-on skills for IT Support / Helpdesk roles. This repo documents my home labs, with screenshots and the troubleshooting scenarios I practiced.

## Labs

| Lab | What I practiced |
|-----|------------------|
| [Active Directory](active-directory/) | Domain controller setup, OUs, user accounts, security groups, shared folders with group-based permissions, Group Policy, password resets, account unlocks, joining a PC to the domain |
| [Microsoft 365 Admin](microsoft365-admin/) | Password resets, MFA re-registration, user licensing, shared mailboxes, group management, offboarding (blocking sign-in) |
| [Action1 Patch Management](action1-patch-management/) | Manual agent install, Deployer for automatic agent rollout across a domain, viewing vulnerabilities (CVEs), deploying missing updates with a scheduled reboot |
| [Jira Service Management](./jira-service-management) | Mock helpdesk queue, ticket categorization, priorities/SLAs, resolving tickets with notes |
